# 留刻 · 分阶段任务计时器（含 macOS 桌面悬浮）

在原有网页版上增量增加 Electron 无标题栏桌面窗。原任务编辑、分阶段倒计时、自动切换、暂停/继续、提前下一步和结束确认均保留。没有新建独立项目，也不需要登录、云服务或付费接口。

## 安装版（1.0.0）

从工作台「下载安装包」下载留刻，将应用拖入 Applications 后打开，无需 Node.js 或终端。工作台 2.2.4 起自动识别安装的留刻（按固定 bundle ID，改名也可识别）。

安装版任务、提示音、悬浮位置和锁定状态保存在 `~/Library/Application Support/StageTimer`，替换应用不会删除设置。旧源码版更新后首次启动会迁移原 `.data` 到这个目录，并保留旧副本；迁移失败停止启动，已有目标不会被覆盖。旧网页 localStorage 保留在原浏览器和 `http://127.0.0.1:43121/` 地址中。

仅提供 Apple Silicon Mac 包。未进行 Apple Developer ID 签名、公证，首次打开可能需要用户在系统设置允许。菜单「留刻计时器 → 退出留刻」退出整个服务。只关闭网页不会停止桌面计时。

构建：先 `npm install` 和 `node node_modules/electron/install.js`，再 `python3 packaging/build.py`。打包采用源文件白名单，排除任务数据、音频、测试记录和本机配置。内置 Node.js 与 Electron 的许可证随包提供。

## 源码启动

1. 双击本目录的 `启动计时器.command`，保留终端窗口。
2. 打开 http://127.0.0.1:43121/ 。若之前已打开页面，请刷新一次加载新版。
3. 点击主界面右上角 **开启悬浮计时**。既可在开始任务前开启，也可在计时途中开启。
4. 在原主界面设置计划、测试声音并开始。可以切换软件、最小化或关闭主网页，保持启动终端运行即可。

当前电脑已安装本项目所需 Electron。终端启动也可使用 `npm start`。首次换到另一台 Mac，需要 Node.js 22+，在本目录执行：

```sh
npm install
node node_modules/electron/install.js
npm start
```

显式运行安装脚本用于兼容 npm 禁止自动执行依赖脚本的设置。依赖版本由 package-lock.json 固定。首次安装需要下载桌面运行时，正常使用不需要联网。

本版原生悬浮针对 macOS，未实现 Windows/Linux 启动路径。仅监听 127.0.0.1。端口占用不会杀掉其他程序；如使用 `PORT=43122 npm start`，应固定使用新地址，浏览器旧地址的数据不会自动跨端口迁移。

## 悬浮窗

- 246 × 132 逻辑像素，无系统标题栏；深色半透明背景、橙色细边框、普通白色等宽数字。
- 使用真正的原生置顶窗口，不是网页内浮层；显示、自动刷新和阶段切换使用不抢键盘焦点的窗口配置。
- 未锁定时按住非按钮区域拖动；移动按渲染帧合并，松开立即保存最终位置。
- 鼠标进入整个悬浮框时显示左侧“打开主界面”与右侧锁定/取消锁定按钮。“打开主界面”优先切回默认浏览器中已有的本工具标签页，没有时才打开新页，锁定时也可用，点击不会拖动或改变计时。macOS 支持 Chrome、Edge、Brave、Chromium 和 Safari；首次可能需要系统的浏览器自动化授权，拒绝时提示打开失败以避免重复开页。其他浏览器和系统仍使用普通打开链接方式；Codex 内嵌浏览器中的页面不在复用范围内。
- 鼠标进入整个悬浮框时显示锁定/取消锁定按钮；移到按钮不会触发离开，移出框后隐藏。锁定只禁止拖动，不禁用全部鼠标事件。
- 点击数字不暂停、不重置、不切阶段。点击解锁不会同时启动拖动。
- 位置与锁定状态保存在 `.data/overlay.json`。打开、拖动结束、显示器变化和唤醒时重新约束到可用屏幕区域。
- 颜色以当前阶段原定时长为分母：剩余 >20% 为白字橙边；20%→5% 线性过渡到红色；≤5% 保持红色。
- 最后 10% 每约 5 秒轻动一次，每次 0.4 秒，位移不超过 2 像素、缩放不超过 1.015。只移动内部视觉内容，不移动窗口；悬停、拖动、暂停或计时结束时停止。系统“减少动态效果”开启时不播放此动效。
- 进入下一阶段重新计算比例。最终显示“计划时间结束”，不替用户认定成果完成。
- 主界面的“关闭悬浮计时”只隐藏窗口，不结束任务。要结束任务，使用原有“结束任务”。

## 计时与数据迁移

未开启过桌面模式时，保留原来的浏览器本地计时与 localStorage 保存。

首次点击开启悬浮时，当前网页的计划和完整计时状态被迁移到本地服务；保持原阶段截止时间，不重新开始。之后统一由 `runtime.mjs` 使用原 `dist/engine.js` 推进计时。网页和桌面窗读取同一状态，不各自推进阶段。

- 桌面计时状态：`~/Library/Application Support/StageTimer/runtime.json`，临时文件写入后重命名保存。
- 悬浮位置/锁定：`~/Library/Application Support/StageTimer/overlay.json`。
- Electron 浏览器数据：`.data/electron/`。
- 桌面启动诊断日志：`.data/desktop.log`。

桌面模式开启后，服务中的计划为主数据，不再用旧浏览器存储覆盖它；网页仍保留一份镜像备份。请勿删除 `.data`。多个浏览器同时打开时读取同一个桌面任务。

正常运行时提醒由桌面组件负责；组件退出后网页可接手。提醒事件先在服务端认领再播放，避免网页和悬浮窗双响；刷新不会重复提醒已经认领的事件。服务/进程恰在认领后崩溃仍可能漏发提醒，不能实现绝对可靠的系统闹钟。

## 声音、通知与窗口限制

- 原网页提示音测试仍可使用；桌面阶段到点使用同样三音提示。音频接口运行成功不等于耳机实际有声，首次使用请实际听一次。
- 桌面组件运行时，通知按钮为“开启桌面通知”，只有用户主动点击后才发送原生通知；系统权限与勿扰模式仍会影响显示。关闭按钮后不会自动重新授权。
- 一般桌面软件上使用原生置顶，并请求跨工作区/全屏显示。但 macOS 全屏空间、独占全屏、系统安全界面、屏幕共享策略及更高层级窗口都可能覆盖或隐藏它，不能保证在所有全屏软件上可见。
- 最小化/关闭主网页不会影响已经开启的桌面计时。终端服务关闭、系统休眠或退出登录后无法准时发出提醒。重新启动服务后按真实时间追赶，跨多个阶段只合并补报一次。
- 系统时钟调整会影响基于时间戳的计时。显示器热插拔时系统提供的新工作区会用于重新定位。
- 当前提示音使用哪个输出设备、系统通知是否弹出、多显示器混合缩放以及全屏剪映，需要在用户实际环境中验证。

## 主要改动

- `dist/app.js`、`dist/index.html`、`dist/remote.js`：保留原界面，增加悬浮入口与服务同步。
- `runtime.mjs`、`server.mjs`：共享计时、保存、提醒去重与桌面启动。
- `desktop/`：原生窗口、有限 IPC 桥、拖动/锁定、渐变与动效。
- `dist/engine.js`：沿用原阶段计时实现。

### 透明与鼠标穿透
悬浮框背景透明，数字保留阴影以提高可读性。锁定后，数字和普通区域的鼠标点击会穿透到下面的软件；主进程持续检测鼠标位置，悬停显示按钮，只在按钮范围内接收鼠标事件，保留打开主界面和取消锁定。解锁后恢复拖动，此时会接收鼠标点击。
本次已检查代码语法、透明外观与锁定切换；在剪辑软件上的真实穿透点击和物理鼠标悬停解锁仍需手动验证。

### 自选提示音
主界面底部「到点提醒」支持内置三声清铃、当前 Mac 的系统提示音和上传音频。上传支持浏览器可解码的 MP3、WAV、M4A、OGG、WebM（最多 5 MB、30 秒）；上传后自动选用，可试听、替换或移除。设置和文件仅保存到本机 `.data/sounds/`，网页与悬浮窗共用选择。系统声音仅在 macOS 上提供；耳机输出、系统静音及浏览器自动播放限制仍需实际试听确认。声音不会自动修改系统音量。

锁定悬浮窗后，平时只显示倒计时数字；鼠标进入时显示中性灰色细边框和操作按钮，移出后隐藏。锁定状态不显示阶段小字，边框不再随剩余时间变红；数字仍保留临近结束的颜色提醒。
