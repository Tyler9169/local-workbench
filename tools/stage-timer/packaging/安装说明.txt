留刻计时器 1.0.0 · Apple Silicon Mac（macOS 13.5+）
将「留刻计时器.app」拖入 Applications，再从应用程序打开。无需 Node.js、终端或账号。
主界面在默认浏览器打开；点击「开启悬浮计时」显示桌面倒计时。
关闭网页不会退出应用；通过菜单栏「留刻计时器 → 退出留刻」停止服务。

工作台 2.2.4 起自动识别 /Applications 和 ~/Applications 中的留刻计时器。
任务、悬浮窗位置、锁定与提示音保存在 ~/Library/Application Support/StageTimer。
升级只替换应用，保留这个数据目录；浏览器网页地址仍为 http://127.0.0.1:43121/。
旧源码版请先退出服务，再启动新版源码一次，完成 .data 到上述目录的一次迁移；原 .data 保留。
仅使用网页、未开启过悬浮的旧任务仍在原浏览器中，请继续使用同一浏览器和地址。

未经 Apple Developer ID 签名、公证。首次打开可能被系统拦截；请核对 GitHub 来源，
由你在「系统设置 → 隐私与安全性」允许。不要关闭系统安全保护。
不包含任何用户任务、音频或设置。提示音、通知受系统音量、权限和休眠影响。
